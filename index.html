02 / About

Design sense, engineering discipline

I'm a developer and UX designer in Pretoria, and I've just finished a BSc in Information Technology (Software Engineering) at Eduvos. My route in started with an NQF Level 5 systems development learnership at iSolve House, where I worked with Java, SQL and the discipline of building to a specification rather than to a mood.

Since then: a UX design internship at Informage RIMS Group, a full-stack development course through the FNB App Academy, a software developer internship at TrotYourGlobe, and the Google UX Design certificate alongside them. That combination is the work I want to keep doing — understanding a problem properly, then writing the code that solves it, with an interface someone can use without being taught.

Most of what I build leans on relational data and plain, well-structured front-end code — Java and SQL underneath, HTML, CSS and JavaScript on top. I'm going deeper into accessibility and applied AI, and I care about doing the work properly: on time, in collaboration, and with the details right.

How I work

  1. 01

    Understand the problem

    Read the brief, question the assumptions, and work out what the software actually has to do before choosing any tools.

  2. 02

    Sketch and structure

    Wireframe the interface and model the data, so the screens and the schema agree before either gets built.

  3. 03

    Build in small pieces

    Work feature by feature in Git, keeping the code readable and the commits honest.

  4. 04

    Test with real use

    Run through it the way a person would, fix what breaks, and tighten the parts that make people hesitate.
